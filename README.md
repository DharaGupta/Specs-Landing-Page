# Iris — Experimental Landing Page
A high-fidelity landing page concept for a futuristic AR glasses brand, designed in Figma and built in React.

This project was created to explore the complete design-to-development workflow — from conceptualizing the visual direction and generating AI-assisted visuals to building a responsive, functional interface and deploying it live.

## ✨ Features
- Responsive layout across desktop and mobile
- Reusable React components
- Dynamic product card rendering
- Add-to-cart interaction with React state
- Form validation
- Responsive navigation and mobile menu
- Scroll animations

## 🛠️ Built With
- React
- JavaScript
- CSS3
- Figma
- Midjourney
- GitHub
- Vercel
